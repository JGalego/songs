# Not a Reflection of Your Performance — music video

Song made with Suno; video rendered live in the browser with TypeScript + three.js.
The end of humanity, told as a series of layoff emails.

## Run

```bash
npm install
npm run dev          # open the printed URL, click to start
```

| Key | Action |
|---|---|
| `space` | play / pause |
| `←` / `→` | seek ±5 s (hold `shift` for ±1 s) |
| `[` / `]` | previous / next section |
| `L` | toggle lyrics |
| `D` | debug overlay (time, section, fps) |

URL params: `?t=180` start at 180 s · `?res=1080` force render height · `?still=205` render one frozen frame (no audio).

## Export an mp4 for YouTube

```bash
npm run export                         # 1080p60 → renders/not_a_reflection_of_your_performance_1080p60.mp4
npm run export -- --from 54 --dur 6    # 6-second test slice
npm run export -- --help               # all options
```

Same pipeline as Context Window (Vite in-process, off-screen Chrome, ffmpeg). The song name comes from the folder
and the length from `src/timeline.ts`. On this laptop 1080p60 renders at ~6 fps, so the full video takes about 50 minutes.

## How it works

The video is a sequence of about 50 short animated scenes, one or two per lyric line, in the style of corporate software
on a navy and pastel gradient: cream cards, stamps, toasts, charts, dashboards. A full-screen 2D stage (`src/stage.ts`)
plays them in order and wipes between them on the cuts; the 3D world (the planet and the empty office) shows through
where a scene leaves the background clear. Everything is a pure function of the time `t`, so live playback and export match exactly.

## Where things live

- `src/scenes1.ts`, `scenes2.ts`, `scenes3.ts` — **the scenes**, in song order. Each has a start and end time and one `draw` function. To change a moment, find the lyric.
- `src/art.ts` — the toolkit: easing, cards, windows, stamps, avatars, and the icons the lyrics call for (tooth, mug, plant, palm tree, sunset, smiley, bin, …).
- `src/stage.ts` — plays the scenes, draws the backdrop and wipes, and the overlays that never go away (headcount, karaoke subtitles, credits).
- `src/timeline.ts` — lyrics (from a Whisper word-level transcription), section times, the headcount curves, credits. Nudge freely.
- `src/karaoke.ts` — generated by `tools/karaoke.py`: when each word of each lyric line is sung (Whisper word timestamps aligned to `LYRICS`). The subtitles fill in word by word from it, karaoke-style.
- `src/camera.ts`, `src/globe.ts`, `src/office.ts` — the 3D parts: the planet going dark, and the empty office whose motion-sensor lights switch off row by row.
