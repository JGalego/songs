# Ghost Notes — music video

Song made with Suno; video rendered live in the browser with TypeScript + three.js.
An AI sings to the musicians it learned from, inside a piano roll: every bright note it writes traces a ghost note
somebody else played first.

The video (not the music) is an homage to the DAW a lot of bedroom producers started on, around 2004. It's an homage,
not a copy: the app is "FrootyLoops", with its own logo (a ghost-shaped plum), invented plugin names, and a skin in the
spirit of the original.

## Run

```bash
npm install
npm run dev          # open the printed URL, click to start
```

| Key | Action |
|---|---|
| `space` | play / pause |
| `←` / `→` | seek ±5 s (hold `shift` for ±1 s) |
| `[` / `]` | previous / next section |
| `L` | toggle lyrics |
| `D` | debug overlay (time, section, beat, fps) |

URL params: `?t=180` start at 180 s · `?res=1080` force render height · `?still=205` render one frozen frame (no audio) · `?clean` or `?nolyrics` hide the lyrics (for posters and thumbnails).

## Export an mp4 for YouTube

```bash
npm run export                         # 1080p60 → renders/ghost_notes_1080p60.mp4
npm run export -- --from 57 --dur 4    # 4-second test slice
npm run export -- --help               # all options
```

Same pipeline as the other songs (Vite in-process, off-screen Chrome, ffmpeg). On this laptop 1080p60 renders at
about 4.5 fps, so the full video takes a little under an hour.

## How it works

Two worlds, one camera. Her bedroom in 2004, at midnight, in 3D: toon-shaded and inked, warm under the desk lamp, a
hillside town lit up outside the window, a cat asleep on the sill, and her at the desk with her headphones on (in the
spirit of the lo-fi study-girl streams). On the beige CRT: the app, her step sequencer and the upload page (a 4:3
canvas through a CRT shader). Far away from it is the piano roll, in 3D: the front sheet is where the AI writes,
and behind it is a stack of glass panes, one per song it learned from, full of ghost notes. A 2D overlay on top carries
the app's toolbar and hint bar, every window the lyrics call up, the karaoke subtitles and the credits.

The bright notes are the sung melody, one note per word: timed by the karaoke word timings and pitched from the vocal
(`scripts/melody.py`). They're drawn as they're sung, growing out of the playhead. Every one of them has a twin: the same
note, already sitting in one of the ghost layers before it was sung. Every layer has its own channel colour, the way the
DAW colours its patterns, and every bright note wears the colour of the ghost it traced, so the melody is a patchwork of
other people's songs. In the choruses, threads run from each bright note back to its twin. In the last one, the twins
come forward and take the line.

Everything is a pure function of the time `t`, so live playback and export match exactly. The step sequencer and the
song position follow the song's real beat grid (135 BPM, from librosa).

## Where things live

- `src/timeline.ts` — **all timing**: sections, lyrics, the beat grid, every story cue (each one hangs off a sung word), how visible the ghosts are, credits. Nudge freely.
- `src/karaoke.ts` — generated by `tools/karaoke.py`: when each word of each lyric line is sung. The first line was re-timed by hand in `scripts/transcript.json` (Whisper heard the intro's vocal chops as words).
- `src/melody.ts` — generated by `scripts/melody.py` (`uv run --with librosa python scripts/melody.py`): the sung melody, one `[start, end, midi]` per word, snapped to D minor.
- `src/songs.ts` — the ghost layers and their channel colours, all seeded: her 16-step pattern (exactly sixteen squares lit), the old man's four cello bars, the session drummer's half-time groove with its ghost notes, the lullaby, and twenty strangers. Also where each bright note's twin is hiding.
- `src/roll.ts` — the 3D piano roll: the front grid, the panes, instanced notes (bright ones written as they're sung, ghosts added up in light), the threads, the keyboard, the playhead and the layers' name tags.
- `src/bedroom.ts` — her room around the monitor, all 3D: desk, lamp, CDs, steaming mug, plants, posters, the calendar at March 2004, fairy lights, bookshelf, the town outside, the cat, her chair, and her.
- `src/screen.ts` — the 2004 monitor and what's on it: the splash screen, the step sequencer, the render dialog, the upload page and its two counters.
- `src/ui.ts` — the overlay: toolbar and hint bar, the ghost layers' track list, the cello video (an old man in a flat cap, playing in a station), the prompts, the View menu, the record sleeve, the velocity lane, the playlist, the voice memo, the mixer, the rename dialog, the fader, subtitles, credits.
- `src/art.ts` — palette, easing, drawing primitives and the logo.
- `src/post.ts`, `src/features.ts`, `src/audio.ts`, `src/math.ts`, `src/text.ts` — shared with the other songs.
- `scripts/export.mjs` — the `npm run export` CLI.
